# Referencias visuales

Imágenes aportadas por el dueño el 2026-10-30 como dirección de tono, no como assets para copiar ni incluir en el bundle.

- `tura-dark-typography.png`: estudio tipográfico oscuro, mucho aire, navegación mínima y una sola pieza central.
- `minimalism-light-editorial.png`: composición editorial clara, tipografía enorme, líneas finas y un único acento rojo.

La aplicación usa estas referencias para **minimalismo editorial**: papel cálido, tinta oscura, un solo acento bermellón, reglas finas, tipografía grande y una acción principal por vista. No se copian logotipos, textos ni layouts de las referencias.
